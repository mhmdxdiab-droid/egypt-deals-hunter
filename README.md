# صياد اللقط — تجربة متابعة أسعار مستقلة

تجربة صغيرة تكتشف جاكيتين من Mobaco تلقائيًا، وتسجل أسعار كل SKU ومقاس ولون. تعمل بجدولة GitHub Actions كل6 ساعات، وتعرض جدول الأسعار في صفحة ملخص التشغيل. لا تستخدم ChatGPT أو خدمات AI.

## الحالة

جمع الأسعار يعمل دون أسرار. Telegram اختياري حتى يتم ضبطه؛ غياب الأسرار لا يعطل الفحص. أول قراءة تحفظ نقطة البداية، وأي نزول لاحق لنفس النسخة المتاحة يعاد التحقق منه قبل الإرسال. الشحن غير معروف، ولا وصف لخصم تاريخي مؤكد لمجرد انخفاض السعر.

افتح Actions ثم Two-jacket price pilot ثم أحدث تشغيل لعرض جدول الأسعار وحالة الفحص. يمكن تشغيل تجربة يدوية من Run workflow. الأخطاء تظهر باللون الأحمر؛ لا تعتبر دورة فاشلة تحديثًا ناجحًا.

## ربط تليجرام

في Settings → Secrets and variables → Actions أضف TELEGRAM_BOT_TOKEN من BotFather وTELEGRAM_CHAT_ID للمحادثة الخاصة بعد ضغط Start في بوتك. لا تضع أيًا منهما في الملفات أو Issues أو المحادثة. راجع CLOUD-START.md لطريقة الربط المحلية مرة واحدة عند الحاجة.

أسعار المنتجات والحالة محفوظة في private/catalog.sqlite3 داخل المستودع العام؛ لا تحفظ قاعدة الهاتف أو settings.json هنا. قاعدة cloud.py لا تحتوي التوكن أو رقم المحادثة. الكود محليًا يستعمل إعدادات مختلفة عن النسخة السحابية.

## الحدود

منتجان فقط في هذه المرحلة. الجدولة قد تتأخر أو تتوقف وفق سياسات GitHub، وقد يمنع المتجر طلبات مصدر GitHub. يلزم فحص أول تشغيل فعلي قبل ادعاء نجاح التشغيل السحابي. التشغيل والتخزين يخضعان لشروط الخطة؛ نستخدم standard ubuntu-latest فقط ولا artifacts أو AI APIs مدفوعة.

لا تسليم مضمون exactly-once عند توقف المضيف قبل حفظ الحالة، ولا إعادة محاولة تلقائية عند غموض تسليم Telegram. قد ينتج عن تعذر دفع الحالة فقدان مقارنة أو تكرار لاحق؛ راجع فشل workflow.
